# 🎛️ DJ Sugar Built-in Samples

## Usage

Drag any file onto a sampler pad. Bank A and Bank B load the DJ Sugar kit by default.

## Sources

The other samples come from myinstants.com and community contributions. Every clip is trimmed to start on the hit and peak-normalized to -1 dBFS.
